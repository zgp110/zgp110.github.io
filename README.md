# zgp110.github.io

Personal academic homepage of **Genpei Zhang (张根培)** — incoming CS PhD student at the University of Wisconsin–Madison (Fall 2026).

🔗 Live site: [https://zgp110.github.io](https://zgp110.github.io)

## Build

This is a [Jekyll](https://jekyllrb.com/) site hosted on [GitHub Pages](https://pages.github.com/). To preview locally:

```bash
bundle install
bundle exec jekyll serve
```

## Structure

- `index.md` — About Me (English)
- `cn.md` — 中文版
- `publications.md` — Publications
- `_config.yml` — site configuration (title, navigation, owner profile, analytics)
- `_layouts/`, `_includes/` — Jekyll templates
- `assets/` — CSS, JS, fonts
